# 量子手记：Shankar 交互伴读

面向高中数学基础读者的中文交互学习伴读。按原书顺序完成第 1 至 8 章，推进到路径积分。共 44 个阅读单元；第六章原书没有编号小节，保持全章连续讲解。第 9 章及后续章节尚未制作。

## 打开

直接双击 `output/量子手记-第1至8章.html`，无需服务器或联网。公式、图示和脚本全部内嵌。学习进度保存在本浏览器；浏览器禁止本地存储时，仅在当前打开期间有效。

[下载完整离线 HTML](https://github.com/HainaHuang729/quantum-notes/raw/HEAD/output/%E9%87%8F%E5%AD%90%E6%89%8B%E8%AE%B0-%E7%AC%AC1%E8%87%B38%E7%AB%A0.html)。请先下载再用浏览器打开；GitHub 文件页面显示的是源代码。

仓库只保留这一份完整导出。原本地目录中第 1 至 2、3、4、5、6、7 章的旧文件名仍为兼容副本，可继续沿用旧文件下保存的阅读位置与进度。

开发需要 Node.js 22 或更新版本。运行 `npm ci` 安装锁定的依赖，再运行 `npm run dev` 预览。

重新生成离线文件：`npm run build`，结果为 `dist/index.html`。`output/` 中为已验收的离线副本；修改后需重新复制该副本。

## 阅读

当前为 PPT 式卡片版，同一时刻只显示一张。每章有自己的封面、内容目录、页码和完成进度。

第 1 至 8 章分别为 92、53、20、45、46、15、59、30 张卡片（均含本章封面），共 360 张；45 个实验（42 个主线、3 个可选）与 106 道原创自测。相关概念、公式和解释合成完整主题，减少连续翻页。

- 使用底部“上一张 / 下一张”或键盘左右方向键翻页；在滑块和输入框中，方向键继续操作控件。
- 用“选择章节”切换章节；点击页码选择本章卡片，侧栏按小节跳转。
- 每章末尾可进入下一章；第 8 章末尾提示本章已读完。
- 自动保存最后阅读的卡片；翻页后实验参数与自测状态在本次打开期间保留。
- 公式和定理引用会切换到目标所在卡片。
- 定义、公式、例子和推导按相邻主题合并，在同一卡片内连贯阅读；实验与自测单独成卡。较长主题或手机上的实验可在卡片内滚动，翻页栏始终可见。
- 旧版卡片链接和保存的阅读位置会定位到相应主题中的原内容。

- 悬停或点击点状下划线术语，打开概念解释。窗口内的术语还能继续展开。
- 点击术语可固定窗口，拖动标题栏移动；按 Esc 逐个关闭。
- 推导可逐步展开；自测回答后显示解释。
- 用滑块、预设按钮做实验。完成一节后可手动标记学习进度，也能撤销。

## 内容与来源

参考 R. Shankar, *Principles of Quantum Mechanics*, second edition, Plenum Press, 1994, Chapters 1–8。本地参考 PDF 存放于 `sources/`，不随仓库或离线 HTML 分发。正文用中文独立讲解，保留小节顺序、主要定义/定理/推导及核对过的公式编号，添加高中到大学数学的过渡解释和原创自测。没有复制原书扫描图，也没有逐题重现原书全部习题。

第 4 章可执行逐次理想测量，比较重新制备与同一样品连测，改变相位和测量基，调节 Gaussian 波包宽度，单步推进时间，交换两个脉冲的顺序。密度矩阵及其纯态/混合态对照保留为原书可选内容。新增加权平均、标准差提示。

第 5 章新增自由波包展宽、箱中能级与拍动、概率流、单势阶散射、精确双缝几何与近轴近似、束缚本征态实化六个实验。保留 90 个源公式编号和 13 道原创自测，新增梯度、散度、散度定理三层前置解释。波包积分、导数级数、有限阱和恒力传播核可按需展开。

第 6 章从 Ehrenfest 定理推导经典近似的条件，保留 12 个源式和原例子，增加平均力、二次势中心与波包宽度、宏观制备尺度三个实验。中心的经典轨道与非零的位置方差可以同时存在。

第 7 章保留 117 个源式与两条求解路线。六个新实验分别比较小振动近似、定态波函数与禁阻区、有限区间的经典对应、Fock 升降阶梯、同一态的能量基与位置图、可选热振子热容。新增阶乘与递推关系提示；星号练习和非 Cartesian 量子化保持可选。

第 8 章保留 38 个源式与 12 道原创自测。四个实验依次观察有限路径族的驻相、逐步消去时间切片节点、短时曲率与势能更新、比较自由/恒力/振子传播核。另有可调固定端点描线台、三步传播流程、相位尺度双图、消元连通图与归一化图解。原书可跳过的 8.6 全部保留为可选深入阅读，二次作用量实验也在其中。单条路径的相位与完整传播核分别说明。

图示使用 interactive-textbook 配套组件及 Anatomy MIT 绘图库。Anatomy 代码与许可证保存在 `scripts/anatomy/`；台架几何可用 `node scripts/anatomy/build-string.mjs` 重新生成。
